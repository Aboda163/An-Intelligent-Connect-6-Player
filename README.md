# Intelligent Connect-6 Player

An intelligent player for Connect-6, an extended version of Connect Four played on an $n \times n$ grid. In this game, players strive to connect six markers in a row horizontally, vertically, or diagonally. After the first player places one stone, players alternate placing two stones per turn.

## 🚀 Features

*   **Minimax Algorithm:** Recursively evaluates game states to determine the optimal strategic move.
*   **Alpha-Beta Pruning:** Optimizes the decision-making process by reducing the number of evaluated game states without sacrificing strategic depth.
*   **Custom Heuristic Functions:** Quickly evaluates board states and captures patterns conducive to winning when exhaustive search is impractical.
*   **Dynamic Board Size:** Allows users to select their desired board size ($n \times n$) before starting the game.
*   **User-Friendly Interface:** Seamless interaction for humans to play strategically against the AI.
